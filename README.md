# Excel Case Dashboard

用于 Excel 课程案例的数据可视化 skill：在原始工作簿副本上制作保留模板、文本框和原生图表的可编辑看板，并输出逐图分析 TXT。

完整执行规则见 [SKILL.md](SKILL.md)。

## 仓库内容

- `agents/`：skill 展示信息。
- `scripts/`：工作簿检查、看板制作、布局修复和配色工具。
- `references/`：课程要求、版式、原生对象验收及制作修复说明。
- `assets/`：成品 Excel、报告参考及课程课件。

## 运行条件

脚本使用 Python 3，部分脚本依赖 `lxml`。原生 Excel 显示、筛选交互和保存重开仍需在实际环境中验证。

参考资源仅用于核对样式和规则；新任务使用用户当次提供的原始数据。
