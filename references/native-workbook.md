# 原生对象、保真与验收

## 编辑路径

记录输入哈希、工作表、源数据和模板绘图。基于文件副本加工，不新建空工作簿重建模板。遵循当前环境表格工具规范；导入导出未必保留绘图、透视缓存、字段按钮，先在临时副本检查往返保真。

- 工具能保留所需对象时，使用其受支持的导入编辑能力，保存后检查原生文件。
- 缺少所需能力时，使用当前可用的原生Excel接口，不假定有Excel或Windows COM。
- 对缺失功能定点处理OOXML时复制原始ZIP，仅替换所需部件、追加对象，未改部件原样保留。用XML库转义文字和公式，不全局替换字符串。
- 不用通用电子表格库全量加载保存来赌文本框、按钮和扩展属性不丢失。图表必须是原生对象，不能先画PNG再插入。
- 无法完成/验证关键原生功能时说明具体缺口，不用静态结果冒充“完成版”。

样式核对按三方分工：原始文件确认继承和保留，成品确认字体/配色/文本框/构图，课件确认图例置顶、按钮、标签等明确要求。尺寸依用户最新要求可调整，以清晰美观为准。不要用“肉眼相似”替代对象样式核对；识别当前原生对象的字体、主题颜色/实际颜色、线条、填充等属性，并结合实际显示对照。

## OOXML要点（仅在需要时使用）

1. 工作表路径由`workbook.xml`及其关系表解析，不能假定“案例数据”总是sheet2。
2. 共享字符串、样式、透视字段与缓存、绘图关系都是局部ID。从成品借用部件时必须重映射，不能直接塞入原文件。若原始文件与成品主题不同，同一个accent索引不保证相同实际颜色；先解析主题映射，必要时在新增对象局部使用匹配的显式颜色，不覆盖整个原始主题来修一张图。
3. 透视表需要真实缓存定义/记录、源范围、字段、行列/筛选项、数据字段、缓存及关系。只写静态汇总不等于透视表；类别变化时更新所有项与缓存。
4. 原生图表在`xl/charts/`（新版也可能是chartEx），由工作表绘图连接。两处图共用相应透视结果，公式、缓存、筛选状态一致。
5. 检查`c:pivotSource/c:name`与公式中的旧工作簿名。示例残留旧文件名前缀；区分当前文件自引用与真正外部链接，更新复制过程的自引用并清理新引入外部依赖，不擅自删除原有无关链接。
6. 按钮可能存于`c14:pivotOptions`的`dropZoneFilter/Categories/Data/Series`与`dropZonesVisible`或新版扩展。隐藏无用按钮时保留所需筛选；实际显示受Excel版本影响，XML标记不能代替原生验证。
7. 绘图锚点、形状变换与真实行高列宽共同决定尺寸。统一水平长度是实际从左到右的物理尺寸一致，不仅是相同单元格跨度；垂直高度允许按图形调整，同排取相同高度、上下沿对齐，不同排可不同高，各排整体左右外沿对齐。纵向定位需基于明确行高与EMU几何，不能只给默认行高却假定引擎不调整；图框不相交且保留可见间隔，并在Excel保存重开后重新检查。锚点需有模板内边距，保证边框四边完整可见。分析页图表区纯白填充，看板图表区/绘图区无填充，两个实例分别设置。
8. 新部件更新`[Content_Types].xml`、`.rels`及唯一ID，保留命名空间扩展、文本框、打印/布局设置。保存正常`.xlsx`，不擅自改宏格式。

## 只读工具

`workbook_audit.py inspect`输出工作表、文本框、锚点、原生图表、系列引用/缓存、透视表和按钮。标准销售字段可独立计算分组统计供核对；其他数据仍可检查对象，不要求套用销售分析。

`check --source ... --dashboard ...`检查原始工作表与案例数据保留、包关系、标题、顶部图例、至少6图/6形式、每分析页透视表与图、看板配对及实际缓存中的总计。还检查图框高宽比、几何相交以及默认行高被规范为14pt后是否可能相压；列宽到物理宽度为近似值，不能代替原生显示。旧工作簿前缀与控件线索需要进一步验证。

非零退出表示静态错误。工具不创建工作簿，也不证明汇总全部正确、控件有效或像素一致。公式缺少缓存时报告未知，不代算任意公式；在实际引擎重算后再核对。JSON留临时QA目录，不交付用户。

## 完成前证据

| 核验 | 通过证据 |
|---|---|
| 输入保留 | 输入哈希未改，输出保留源数据、说明和未选模板；原文本框可编辑、格式保留 |
| 汇总正确 | 每图金额/数量与原始明细独立汇总一致，期间/分母正确，无重复总计 |
| 分析适配 | 整体到基层，至少6图/6形式，有业务意义，需求分析逐行对应 |
| 原生对象 | 真实透视表；两处图可编辑系列/格式、使用同一来源，不是贴图或另抄数字 |
| 动态验证 | 在看板操作“全部”和两个类别，两处图同步、数值与源匹配，恢复交付状态 |
| 视觉验证 | 完整看板和每页图实际清晰，水平长度统一、垂直高度按排调整并在同排对齐、四边框完整，非饼必要图例置顶、饼图无图例且名称/比例在扇区内，分析页白底、看板透明，无截字/覆盖/屏外漏图；重开无修复提示 |
| 报告一致 | TXT图名顺序口径与图一致，新数据结论，约一页且有总分析 |

结构、数据、交互和视觉分别验证。无原生应用证据不能声称“已在Excel验证交互”或“完全复刻”。用户负责提交截图，不影响制作时必要的内部视觉检查。

颜色验收需覆盖深色、较浅有色与白底三个背景场景：分别查看标题、图例、轴刻度、数据线、网格线、文本框，以及饼图每个扇区的标签。背景明暗会改变文字和线条的清晰度，结构、数值和尺寸检查通过不代表颜色已通过。
